# Upstream template

This package is based on [lcestou/dsh-oh-my-claude](https://github.com/lcestou/dsh-oh-my-claude), version 1.5.5, commit `19a528fcab3f3a462935b0aa154d68e170cdedb2`.

The upstream MIT license and copyright notice are retained in LICENSE. The original implementation provides the Claude Code adapter, sessions, approval relay, model catalog, settings, and conversation panel.

Local changes preserve the `dsh-claude-ssh` package identity and add verified dsh-remote workspace routing and per-workspace model visibility. Build and test commands use the existing pnpm/Node workspace. Upstream documentation describes the template's features; this package's README describes installation and local compatibility rules.
